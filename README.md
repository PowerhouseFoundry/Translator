# POWERHOUSE LANGUAGE BRIDGE — v1.4

A separate West SILC Powerhouse communication and translation app, based on the uploaded **Tell Me** board. The original Symbol Talker and its data are unchanged.

## What's new

- One-screen iPad landscape/portrait layouts, keyboard and Talker input, and full-screen control from v1.1 remain in place.
- **Free app-hosted backup voices** using [eSpeak NG](https://github.com/espeak-ng/espeak-ng) when you deploy the COMPLETE project with the included **Dockerfile**. The Docker image installs an open-source synthesiser and produces speech audio on the server. An iPad only plays the resulting sound: **no voice packs need to be installed on the iPad**.
- The app now prefers matching iPad / device voices over the robotic eSpeak backup. Choose Best available (recommended), iPad / device or App backup under the green Speak button. The choice is saved per device. Tap Speak again to stop. It will not knowingly substitute a different language when selecting a listed device voice.
- No new accounts, API keys or paid voice service are needed for the speech feature. The service requires an internet connection between the iPad and your hosted app. It is not an offline voice download.
- Both "Hear my message" and "Speak translation" use the same voice pathway.

## IMPORTANT: Which file to use

**To get free voices on all classroom iPads, deploy the complete ZIP as a Docker app.** Only the backup voices are generated by the server; device speech requires a matching voice installed or exposed by the browser. Neither type is included in the single HTML file.

- `Language-Bridge-Standalone.html`: quick local test of layout, Talker, keyboard and translation; **speech remains dependent on the device's built-in voices**. The standalone HTML does not contain the speech engine.
- `index.html` + files + `server.js` + `Dockerfile`: the **recommended classroom app**, using server-generated free speech.

## Set up on Render (recommended)

1. Upload **all** contents of the ZIP to a new GitHub repository. Keep `Dockerfile`, `server.js`, `index.html`, `app.js`, `styles.css`, `languages.js`, `talker-data.js`, `assets` and the other files at the top level.
2. In Render, create a new **Web Service** and connect your repository. Choose **Docker** as the runtime (or use the included `render.yaml` Blueprint). Do not select Node runtime if you need the included speech engine.
3. Deploy. Docker installs the free eSpeak NG speech package; `server.js` generates audio on demand. No keys are required for speech.
4. Open the new HTTPS app link on an iPad. Select English → French, type "Hello", translate, then press Speak. Check for **"iPad voice"** or **"App backup voice · synthetic"** below the Speak button. Best available uses a matching device voice first; otherwise it tries the server backup.
5. For an app-like full screen, open the HTTPS link in Safari, choose **Share → Add to Home Screen → Open as Web App** (if available) and launch from the Home Screen. The Full screen button in the app also gives a compact screen view, though Safari can retain its own chrome.

### Translation and charges

This speech upgrade **does not change how text is translated**. By default the app uses a free but limited online MyMemory translation service. Some pairs, particularly Cantonese and Punjabi (Shahmukhi), may be unsupported or unreliable. For more complete translation coverage, set the optional `GOOGLE_TRANSLATE_API_KEY` environment variable **in Render**, not in the HTML. Google Cloud Translation may incur charges.

The app-hosted eSpeak backup voice may sound robotic; translations themselves may contain errors. eSpeak NG's Arabic support is significantly better for text with vowel marks (diacritics); ordinary unvowelled Arabic may be pronounced incorrectly. Punjabi scripts/dialects and Chinese pronunciation should be checked with fluent speakers before teaching. **Do not assume that every listed translation language has a usable speech voice.**

## Local testing with Node.js

Run `npm start`, then open http://localhost:3000. Server speech is enabled only if `espeak-ng` or classic `espeak` is installed on that computer. The supplied Dockerfile installs eSpeak NG automatically when deployed.

For a quick speech status check visit `/api/status` on your hosted domain. It returns `speechAvailable: true` and the installed voice codes when the engine is correctly installed.

## Files

- `index.html`, `styles.css`: responsive iPad interface
- `app.js`: Talker, keyboard, translation and two speech methods (app-hosted and device)
- `talker-data.js`, `languages.js`: vocabulary, 86-language catalogue and keyboard layouts
- `assets/`: West SILC branding and icons from the source Symbol Talker
- `server.js`: translation proxy and speech endpoint. eSpeak WAV audio is re-encoded as a Safari-friendly 44.1 kHz MP3 by FFmpeg (with WAV fallback if FFmpeg is unavailable).
- `Dockerfile`: installs the free open-source speech engine and FFmpeg for Render or any Docker platform
- `render.yaml`: optional Render Blueprint
- `Language-Bridge-Standalone.html`: single-file version, **device speech only**

## Privacy / licensing

Short message text is sent to the server to generate speech and to the selected translation provider to translate. The app does not need learner logins. Avoid entering identifying, medical or sensitive personal information. The app is for educational communication support, not certified interpreting.

[eSpeak NG](https://github.com/espeak-ng/espeak-ng) is licensed under GPL-3.0-or-later; the Docker image installs it from the Debian software repositories, and corresponding source is available from the upstream project. Review the licence if you redistribute the container. Speech generation has no per-request licensing fee, but your hosting service may have running costs.

## v1.3 — smoother speech and switching voices

Version 1.2 always selected the app-hosted eSpeak voice when one existed. This could sound electronic and was not ideal for learners. Version 1.3 prefers a matching local iPad / device voice (often more natural) when available. The backup engine is retained for languages that do not have a local voice. Server audio is converted into standard 44.1 kHz mono MP3 where FFmpeg is available to reduce decode issues on mobile Safari. **Encoding cannot make eSpeak itself sound natural.** Choose the voice mode using the compact selector below the Speak button.

To update an existing Render deployment, replace the app files in your existing GitHub repository with the contents of this ZIP and commit the changes. Render will redeploy automatically if Auto Deploy is enabled. Keep your existing Render environment variables and service; do not delete them. Try a hard reload / close and reopen the iPad app once Render reports Live.

The standalone HTML is for local visual testing and device-based voices. It cannot include the Docker server speech engine.

## v1.4 — translation reliability and Render 502 fix

- Replaced the deprecated `apple-mobile-web-app-capable` meta tag with `mobile-web-app-capable`.
- The old `/api/translate` code returned HTTP 502 for *every* third-party translation problem. It now distinguishes free-provider limits (429), unsupported language pairs (422), and unavailable services (503) with a useful message on screen. HTTP status alone cannot fix an unreliable third-party service.
- The free mode no longer automatically makes dozens of translation requests when loading a Talker board. Instead, selecting a word translates it on demand. The board's untranslated labels remain English until translated. Full automatic board labelling requires the configured Cloud Translation provider.
- Fixed the hosted app's error handling so a failed request doesn't silently launch another request directly from the iPad.
- Added an optional `MYMEMORY_CONTACT_EMAIL` environment variable for the free provider; its availability and daily limits are outside our control. This setting should be a staff/organisation contact, never a learner address.
- **Recommended for dependable daily classroom translation:** configure `GOOGLE_TRANSLATE_API_KEY` as a secret in Render's Environment section and enable Cloud Translation API v2 in Google Cloud. Google requires an account with billing enabled; its free monthly credit applies subject to current pricing, after which charges may apply. Do not paste keys into GitHub, frontend code or screenshots.
- To update, replace files in your existing repository and commit. Don't delete or recreate the Render service, and keep the existing environment variables and files.
- **Test**: visit `/api/status` and check `provider` (`google` or `free`). Then translate `Hello` from English to French; the app now displays the provider's issue when translation fails.
