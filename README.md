# POWERHOUSE LANGUAGE BRIDGE — v1.2

A separate West SILC Powerhouse communication and translation app, based on the uploaded **Tell Me** board. The original Symbol Talker and its data are unchanged.

## What's new

- One-screen iPad landscape/portrait layouts, keyboard and Talker input, and full-screen control from v1.1 remain in place.
- **New free app-hosted voices** using [eSpeak NG](https://github.com/espeak-ng/espeak-ng) when you deploy the COMPLETE project with the included **Dockerfile**. The Docker image installs an open-source synthesiser and produces speech audio on the server. An iPad only plays the resulting sound: **no voice packs need to be installed on the iPad**.
- If an app voice isn't available, try the matching device voice; it never knowingly substitutes an English voice for an unsupported language. The button displays which option is available. Tap the button again to stop speech.
- No new accounts, API keys or paid voice service are needed for the speech feature. The service requires an internet connection between the iPad and your hosted app. It is not an offline voice download.
- Both "Hear my message" and "Speak translation" use the same voice pathway.

## IMPORTANT: Which file to use

**To get free voices on all classroom iPads, deploy the complete ZIP as a Docker app.** The voices are generated by the server; they are not stored in the single HTML file.

- `Language-Bridge-Standalone.html`: quick local test of layout, Talker, keyboard and translation; **speech remains dependent on the device's built-in voices**. The standalone HTML does not contain the speech engine.
- `index.html` + files + `server.js` + `Dockerfile`: the **recommended classroom app**, using server-generated free speech.

## Set up on Render (recommended)

1. Upload **all** contents of the ZIP to a new GitHub repository. Keep `Dockerfile`, `server.js`, `index.html`, `app.js`, `styles.css`, `languages.js`, `talker-data.js`, `assets` and the other files at the top level.
2. In Render, create a new **Web Service** and connect your repository. Choose **Docker** as the runtime (or use the included `render.yaml` Blueprint). Do not select Node runtime if you need the included speech engine.
3. Deploy. Docker installs the free eSpeak NG speech package; `server.js` generates audio on demand. No keys are required for speech.
4. Open the new HTTPS app link on an iPad. Select English → French, type "Hello", translate, then press Speak. Check for **"Free app voice · no installation"** below the speech button.
5. For an app-like full screen, open the HTTPS link in Safari, choose **Share → Add to Home Screen → Open as Web App** (if available) and launch from the Home Screen. The Full screen button in the app also gives a compact screen view, though Safari can retain its own chrome.

### Translation and charges

This speech upgrade **does not change how text is translated**. By default the app uses a free but limited online MyMemory translation service. Some pairs, particularly Cantonese and Punjabi (Shahmukhi), may be unsupported or unreliable. For more complete translation coverage, set the optional `GOOGLE_TRANSLATE_API_KEY` environment variable **in Render**, not in the HTML. Google Cloud Translation may incur charges.

The selected-language speech voice may be robotic; translations themselves may contain errors. eSpeak NG's Arabic support is significantly better for text with vowel marks (diacritics); ordinary unvowelled Arabic may be pronounced incorrectly. Punjabi scripts/dialects and Chinese pronunciation should be checked with fluent speakers before teaching. **Do not assume that every listed translation language has a usable speech voice.**

## Local testing with Node.js

Run `npm start`, then open http://localhost:3000. Server speech is enabled only if `espeak-ng` or classic `espeak` is installed on that computer. The supplied Dockerfile installs eSpeak NG automatically when deployed.

For a quick speech status check visit `/api/status` on your hosted domain. It returns `speechAvailable: true` and the installed voice codes when the engine is correctly installed.

## Files

- `index.html`, `styles.css`: responsive iPad interface
- `app.js`: Talker, keyboard, translation and two speech methods (app-hosted and device)
- `talker-data.js`, `languages.js`: vocabulary, 86-language catalogue and keyboard layouts
- `assets/`: West SILC branding and icons from the source Symbol Talker
- `server.js`: translation proxy and safe WAV generation endpoint
- `Dockerfile`: installs the free open-source speech engine for Render or any Docker platform
- `render.yaml`: optional Render Blueprint
- `Language-Bridge-Standalone.html`: single-file version, **device speech only**

## Privacy / licensing

Short message text is sent to the server to generate speech and to the selected translation provider to translate. The app does not need learner logins. Avoid entering identifying, medical or sensitive personal information. The app is for educational communication support, not certified interpreting.

[eSpeak NG](https://github.com/espeak-ng/espeak-ng) is licensed under GPL-3.0-or-later; the Docker image installs it from the Debian software repositories, and corresponding source is available from the upstream project. Review the licence if you redistribute the container. Speech generation has no per-request licensing fee, but your hosting service may have running costs.
